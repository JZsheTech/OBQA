# M0 Development Environment & Repository Skeleton — Execution Plan

The steps below align with the M0 DoD in `docs/en/Develop_Road_Map.md`: launch a FastAPI backend via `uvicorn` and expose a frontend health check that reaches `GET /healthz`.

## 1. Prepare Local Tooling
- Install Conda (Miniconda/Anaconda) and Node.js 18+ with npm.
- Create workspace root at `/data2/jproject/OBQA` (already synced).

## 2. Create Conda Environments
1. `conda create -n quest python=3.11 -y`
2. `conda activate quest`
3. `pip install fastapi uvicorn[standard] python-multipart`
4. (Optional for later milestones) `pip install dspy`
5. `conda create -n jzMinerUVllm python=3.10 -y`
6. Defer MinerU package installation until MinerU integration (M2) to keep M0 lightweight.

## 3. Stand Up OceanBase (background requirement)
- Pull the single-node demo image: `docker pull oceanbase/oceanbase-ce`
- Run the container with data volume and default ports (see `dependency/oceanBaseDemo/README`).
- Verify the container is healthy via `docker logs` before running backend tests that touch the DB.

## 4. Backend Skeleton & Health Endpoint
1. Ensure directories match the scaffold:
   - `EviQAsys/backend/app/api`
   - `EviQAsys/backend/app/services`
   - `EviQAsys/backend/app/repositories`
   - `EviQAsys/backend/app/schemas`
2. Add `EviQAsys/backend/app/main.py`:
   ```python
      from fastapi import FastAPI
      from fastapi.middleware.cors import CORSMiddleware

      app = FastAPI(title="EviQAsys API", version="0.1.0")

      # ✅ Add this section
      app.add_middleware(
         CORSMiddleware,
         allow_origins=["*"],  # 开发阶段允许所有来源（生产可改为具体域名）
         allow_credentials=True,
         allow_methods=["*"],
         allow_headers=["*"],
      )

      @app.get("/healthz")
      async def health_check() -> dict[str, bool]:
         return {"ok": True}

   ```
3. If needed, expose the FastAPI app inside `EviQAsys/backend/app/api/__init__.py` to keep import paths stable (per docs/en structure).
4. Install backend dev dependencies (pytest, httpx) later; keep M0 focused on healthz.

## 5. Backend Run & Verification
1. Activate `quest`: `conda activate quest`
2. From repo root run:
   ```bash
   uvicorn EviQAsys.backend.app.main:app --reload --port 9075

   ```
3. Confirm health:
   - `curl http://127.0.0.1:9075/healthz`
   - Expected response: `{"ok": true}`
4. Keep the server running for frontend calls.


## 6. Frontend Skeleton & Health Fetch (JavaScript Version)

1. Inside `EviQAsys/frontend`, initialize a **Vite + React (JavaScript)** project:

   ```bash
   npm create vite@latest . -- --template react-swc
   ```

2. Remove default demo files and keep only the minimal structure:

   ```
   src/
     api/
     components/
     pages/
   ```

3. Add `src/api/client.js`:

   ```js
   export async function healthCheck() {
     const res = await fetch("http://127.0.0.1:9075/healthz")
     if (!res.ok) {
       throw new Error(`Health check failed: ${res.status}`)
     }
     return res.json() // returns { ok: boolean }
   }
   ```

4. Create a landing page `src/pages/Home.jsx`:

   ```jsx
   import React, { useEffect, useState } from "react"
   import { healthCheck } from "../api/client"

   function Home() {
     const [status, setStatus] = useState("checking...")

     useEffect(() => {
       healthCheck()
         .then((data) => setStatus(data.ok ? "Backend OK ✅" : "Backend Not OK ❌"))
         .catch((err) => setStatus(`Error: ${err.message}`))
     }, [])

     return (
       <div style={{ padding: "2rem", fontFamily: "sans-serif" }}>
         <h1>EviQAsys Frontend</h1>
         <p>Health Check Result: {status}</p>
       </div>
     )
   }

   export default Home
   ```

5. Update `src/main.jsx` to mount the home page:

   ```jsx
   import React from "react"
   import ReactDOM from "react-dom/client"
   import Home from "./pages/Home"

   ReactDOM.createRoot(document.getElementById("root")).render(
     <React.StrictMode>
       <Home />
     </React.StrictMode>
   )
   ```

6. Run and verify:

   ```bash
   npm install
   npm run dev -- --host --port 5273
   ```

7. Visit [http://127.0.0.1:5273](http://127.0.0.1:5273):

   * The page should display **“Backend OK ✅”** if the FastAPI server (`http://127.0.0.1:9075/healthz`) is live.
   * Otherwise, error messages will appear in the browser console or on the page.
