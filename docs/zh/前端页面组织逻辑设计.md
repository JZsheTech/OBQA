# 页面组织和逻辑

## 顶部标签栏
知识库主页、chat历史

## 顶部导航栏
根据当前所处的页面位置不同存在下面几种状态：

home 位于主页
collection名 位于某个collection的管理页
collection名 > chat名 位于针对某个collection的某个chat中

collection名 > 文档名 位于某个document的管理页
collection名 > 文档名 > chat名 位于针对某个document的某个chat中



## 页面1-知识库主页

要展示的内容和组件
- collection列表，点击其中的一个条目将跳转到对应Collection的文档管理页面
	- 列表的条目要展示下面的信息: collection name、 created_at时间、 description描述(截取前面部分显示)
- 新建collection的 "+" 按钮
- 新建collection的弹出组件： 要求输入collection name 和 description描述
- collection搜索组件： 按关键词搜索collection name 或者 description的搜索框(搜索后collection列表中只显示过滤后符合条件的collection，并变换一个颜色，加一个小提示searched result，允许选择按 name搜索还是按description搜索)
- reset按钮 ： 重置搜索视图和搜索框。

## 页面2-collection页

要展示的内容和组件：
- collection的完整信息
	- collection name
	- collection description
	- collection created date

- 文档document列表组件
	- 显示当前collection中的所有文档的列表，仅包括title和file_name信息
	- 点击其中的1个条目将跳转至对应的document页。
- 上传文档的button "+"按钮 (点击后允许用户选择多个本地文件上传到指定的collection)
- 搜索框：按关键词搜索/全文检索：document tile/abstract/md_text 的搜索框,按全文检索相似度从高到低返回topK。 (允许选择按tile还是abstract还是按md_text(文档全文)搜索)
- 搜索视图：只展示符合搜索条件的document组成的列表，默认为空
	- 列表中的每个条目包括该document的title和file_name信息
	- 点击其中的1个条目将跳转至对应的document页。
- reset按钮 ： 重置搜索视图和搜索框。

- collection聊天历史组件
	- 以列表的形式展示针对当前collection的所有chat条目。
	- 每个chat条目都展示一下chat name。

简单collection-RAG搜索框和列表：
- 允许用户给关键词或者短句，调用后端的RAG方法，将检索到的element的text_content直接以列表的形式展现出来。点击某个text_content后可弹出完整的片段组件，并允许复制，列表中显示时采取截断显示的方法。

## 页面3 document页

要展示的内容和组件：

当前document的详细信息
- 所属的collection name
- title
- file_name
- num_pages
- element_count

abstract文本块展示
- abstract

- document聊天历史组件:
	- 以列表的形式展示针对当前document的所有chat条目。
	- 每个chat条目都展示一下chat name。

简单document-RAG搜索框和列表：
- 允许用户给关键词或者短句，调用后端的RAG方法，将检索到的element的text_content直接以列表的形式展现出来，点击某个text_content后可弹出完整的片段组件，并允许复制，列表中显示时采取截断显示的方法。


## 页面4-问答页(针对单个collection)
左侧展示用户问题 和 系统回答，类似于chatgpt的对话形式
右侧展示预览的pdf，并给出一个下拉框，用于选择该collection中的不同document，其中显示document的title。
当用户点击系统回答中出现的evidence锚点时，右侧pdf预览界面能直接跳转到对应的文档的对应页面并高亮相关element

## 页面6-chat-history页面

- collection level的chat history列表
	- 每个条目前注明collection_name，然后跟上chat_name，点击后可跳转到对应的collection问答页

- document level的chat history列表
	- 每个条目前注明collection_name > document title, 然后跟上chat_name，点击后可跳转到对应的document问答页

列表中条目顺序按照chat的创建时间(created_at)排序。
