# 技术栈
笔记本：开发者本地的机器
服务器：前后端应用部署的机器

前端：React（笔记本 Chrome 浏览器内运行）
后端：Python FastAPI（服务器 Conda 环境 `quest`）
数据库：OceanBase（服务器 Docker 容器部署）
文档预处理：MinerU（服务器另一个 Conda 环境 `jzMinerUVllm`，以本地 FastAPI 形式提供服务，与主要开发环境解耦）
Agent 组织与 LLM 调用：DSPy（包名 `dspy`，服务器 Conda 环境 `quest`）

# 嵌入与检索

- 多模态嵌入：使用 vLLM 暴露的 OpenAI `/v1/embeddings` 兼容接口（默认模型 `jinaembeddingv4`，维度 2048）。配置项通过环境变量控制：`EMBEDDING_ENDPOINT`、`EMBEDDING_MODEL`、`EMBEDDING_TIMEOUT_S`、`EMBEDDING_MAX_RETRIES`，以及可选的 `EMBEDDING_API_KEY`、`EMBEDDING_API_KEY_HEADER`。
- 嵌入服务封装在 `EviQAsys/backend/app/services/embedding/embedding_service.py`，支持纯文本、文本+图像（image/table/equation）混合请求，并在写入前校验维度是否与 `VECTOR_DIM` 一致。
- 向量入库：`elements.vec_embedding` 类型为 `VECTOR(VECTOR_DIM)`，由 `ElementsRepository.update_embeddings()` 批量写入（SQL `CAST`）。
- 检索：`services/retrieval/retriever.py` 调用仓储层在 Python 侧计算 cosine 相似度的 TopK，并提供兜底的关键词检索（`search_mode=fulltext`）。
- 手工验证脚本：`python EviQAsys/backend/tests/manual/test_m3_embedding_and_retrieval.py --collection-id <id> --query "<question>"`，会先补齐缺失向量，再打印 TopK 元素（`doc_id/page_no/bbox/score`）。
